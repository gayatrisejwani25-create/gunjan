Objective of the experiment

📐 Understanding the Chain Rule

The aim of this virtual lab is to understand and apply the Chain Rule for differentiating composite functions. Students will explore how the derivative of a composite function f(g(x)) is the product of the derivative of the outer function evaluated at the inner function times the derivative of the inner function.

By the end of this experiment, learners will be able to:

  • State and prove the Chain Rule formula: dy/dx = (dy/du) · (du/dx).
  • Differentiate composite functions including polynomials, trigonometric, exponential, and logarithmic forms.
  • Apply the Chain Rule in multi-step differentiation.
  • Use the Chain Rule in real-world applications like related rates problems.

Theory: Chain Rule

Derivative of composite functions

📌 Definition

If y = f(u) and u = g(x) are both differentiable functions, then the composite function y = f(g(x)) is differentiable and its derivative is given by:

dy/dx = (dy/du) · (du/dx) = f'(g(x)) · g'(x)

📖 General Form

For composite function h(x) = f(g(x)), we have h'(x) = f'(g(x)) · g'(x). This is often remembered as "derivative of the outside, times derivative of the inside".

🔢 Step-by-step Procedure

  • Identify the outer function f(u) and the inner function u = g(x).
  • Differentiate the outer function with respect to u → f'(u).
  • Differentiate the inner function with respect to x → g'(x).
  • Multiply them: f'(g(x)) * g'(x).

✨ Examples

  • Example 1: y = sin(x²) → outer: sin(u), inner: x² ⇒ dy/dx = cos(x²)·2x.
  • Example 2: y = (3x+1)⁵ → dy/dx = 5(3x+1)⁴·3 = 15(3x+1)⁴.
  • Example 3: y = e^(tan x) → dy/dx = e^(tan x)·sec²x.
